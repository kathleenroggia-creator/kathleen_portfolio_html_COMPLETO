02 — Version Manager

Plugin para reduzir uma tarefa repetitiva dentro do Figma

Durante o desenvolvimento de interfaces, identifiquei um problema recorrente: atualizar manualmente números de versão em dezenas de telas.

contexto

Arquivos com muitas telas exigiam alterações repetitivas e aumentavam a chance de inconsistência.

problema

A mesma versão precisava ser encontrada e atualizada manualmente em múltiplas ocorrências.

solução

Criação de um plugin capaz de localizar os textos de versão e atualizar as ocorrências de uma única vez.
